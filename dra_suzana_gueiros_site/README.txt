# Site Demo — Dra. Suzana Gueiros

Landing page premium para demonstração.

## Como abrir

1. Extraia o ZIP.
2. Abra `index.html` no navegador.

## Configurar WhatsApp

Abra:
`js/script.js`

Procure:

whatsapp: "5581XXXXXXXXX"

Troque pelo número da Dra. Suzana com DDI + DDD.
Exemplo de formato:
5581999999999

Não coloque espaços, parênteses ou hífens.

## Fotos

Substitua os arquivos:

assets/advogada-principal.jpg
assets/advogada-sobre.jpg

Galeria:
assets/galeria/foto-01.jpg até foto-06.jpg

Projetos:
assets/projetos/projeto-01.jpg até projeto-03.jpg

## Vídeos

Edite o array `videos` em `js/script.js`.
Para YouTube, use uma URL de incorporação, por exemplo:
https://www.youtube.com/embed/ID_DO_VIDEO

## Informações da OAB e Instagram

Também ficam no início de `js/script.js`.

## Observação

Os textos institucionais foram mantidos informativos e sem promessas de resultado. Antes de publicar, revise os dados profissionais e as informações de atuação conforme os dados oficiais da advogada.
